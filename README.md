# Raylib Flecs Project Template

Small game template for Raylib and Flecs using CMake as the build system.

# Features

- Automatically installs Raylib and Flecs using FetchContent feature if the libraries are not found globally.

- Includes basic editorconfig config.

- Automatically hides build folder and .vscode folder if using Visual Studio Code.

# What to do?

You can simply clone this repository, and delete the .git hidden folder to start a new repository.

You should edit the `project` name inside CMakeLists.txt

Change the LICENSE if you do not like GPL3.0
